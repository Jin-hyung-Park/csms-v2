# 💳 CU 복지포인트 충전 가이드

복지포인트 충전은 아래 순서로 진행됩니다.

| 단계 | 내용 |
|------|------|
| 1️⃣ | CSMS에서 충전할 복지포인트 확인 |
| 2️⃣ | POS에서 카드 잔액 확인 |
| 3️⃣ | 카드별 충전금액 산정 (A − B = C) |
| 4️⃣ | POS에서 충전 |
| 5️⃣ | 지급대장 작성 |
| 6️⃣ | 영수증 출력 및 보관 |
| 7️⃣ | POS 시재 불일치 해결 |

- 이 금액을 **A. 충전금액** 으로 사용합니다.

> 📷 *(이미지 추가 — 조회1, 조회2)*

## 2️⃣ POS에서 카드 잔액 확인하기

1. POS 메뉴에서 **서비스 > 기프트카드 잔액조회** 로 이동합니다.
2. 기프트카드 **뒷면 바코드**를 인식시키면 잔액이 화면에 표시됩니다.
3. 카드별 잔액을 기록합니다. → **B. 잔액**

---

## 3️⃣ 카드별 충전금액 산정하기

CSMS에서 조회한 **A. 충전금액** 에서 카드의 **B. 잔액** 을 차감하여 실제 충전할 금액을 계산합니다.

```
A. 충전금액  −  B. 잔액  =  C. 충전대상금액
```

| 항목 | 예시 |
|------|------|
| A. 충전금액 | 100,000원 |
| B. 잔액 | 15,000원 |
| **✅ C. 충전대상금액** | **85,000원** |

> 💡 B. 잔액이 A. 충전금액보다 많은 경우, 해당 카드는 충전하지 않아도 됩니다.

---

## 4️⃣ 충전하기

1. POS 첫 화면에서 기프트카드 **바코드를 인식**시키면 충전 메뉴로 진입합니다.
2. 카드별로 **C. 충전대상금액**을 입력합니다.
3. 팝업에서 **확인**을 선택한 후 **현금 전액결제**로 결제 처리합니다.
4. 카드마다 위 과정을 반복합니다.

---

## 5️⃣ 지급대장 작성하기

- 지급대장에 충전일, 근무자명, 충전금액을 기록합니다.
- 근무자들이 서명할 수 있도록 **일지에 공지**합니다.

---

## 6️⃣ 기프트카드 충전 영수증 출력하기

비용 처리를 위해 충전 영수증을 출력하여 별도 보관합니다.

**🖨️ 출력 경로:**

```
OPC  →  정산  →  영수증조회  →  충전 일자 선택
→  거래항목 영역의 [선택] 버튼 클릭
→  팝업에서 "20. 기프트카드충전" 체크 후 [선택]
→  조회  →  전체인쇄  →  바로인쇄
```

> ⚠️ 조회된 데이터가 맞는지 반드시 확인한 후 출력해주세요.

---

## 7️⃣ POS 시재 불일치 해결하기

기프트카드 충전을 **현금결제**로 처리했기 때문에, 총 충전금액만큼 시재가 부족하게 됩니다.

- 근무자 교대 시 혼선을 방지하기 위해, **전일 금고보관 금액에서 총 충전금액만큼 보충**합니다.
